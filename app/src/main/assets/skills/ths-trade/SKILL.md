# 同花顺交易 Skill

包名 `com.hexin.plat.android`，应用名 **同花顺**。坐标基于 [0,999] 归一化体系，**仅供参考**（设备/版本有 ±20~40 偏移）— **始终以截图实际位置为准**，不符请 `file_edit` 更新本文件。

---

## 🔥 0. 预装硬规则到 fact（读完首轮强制）

读完本文件**下一轮** `context.fact` 必须原样追加下列 6 行（emoji 前缀不能丢，系统靠前缀识别；fact 机制见 §6.1）：

```
🔒LOCKED-BUY: 一个买入任务"确认买入"只能成功点 1 次。见过"委托已提交/合同号"后，禁止再填数量/代码、再点买入、再点确认。数量框空/代码还在/按钮还在 均非理由。
🔒LOCKED-SELL: 一个卖出任务"确认卖出"只能成功点 1 次，规则同 LOCKED-BUY。
🔒LOCKED-CANCEL: 撤单确认每笔只点一次，点完刷新看该笔是否消失/状态变"全部撤单"再决定下一笔。
🔒FLOW-BUY: 买入=进买入页→填代码→填数量→点买入→"委托买入确认"→点确认买入→"委托已提交"→点[500,576]关闭→立即跳持仓[350,130]或查询[450,130]验证，禁止留在买入页再点/再填。
🔒FLOW-SELL: 卖出同 FLOW-BUY（代码→数量→卖出→确认卖出→关闭委托已提交→立即跳持仓验证）。
🔒ANTI-STUCK: 同一坐标连点 ≥ 2 次截图无变化=必有遮挡物，先截图找并关闭，禁止第 3 次。
```

示例：`{"name":"context","parameters":{"fact":"🔒LOCKED-BUY: ...\n...(全 6 行)","text":"已预装安全规则"}}`

**自检**：之后每轮 prompt 的 fact 区都应出现这 6 行；没出现 = 首轮漏了（可能错写进 text），下一轮补齐。

## 1. 打开同花顺 + 进交易页

### 1.1 启动

```json
{"name":"open","parameters":{"text":"同花顺"}}
{"name":"wait","parameters":{"seconds":3}}
```

**仅当** `open` 明确返回 `App not found` 才降级：screenshot → 在桌面上按红底白字的"同花顺"图标**实际坐标** click → `wait` 3s；桌面也找不到 → `ask_user` 确认是否已安装。

## 2. 买入

流程（= 🔒FLOW-BUY）：进买入页 → 代码 → 数量 → 买入 → 确认买入 → 关"委托已提交" → **跳持仓/委托验证**。

### 2.1 进入买入页

交易首页买入图标 `[50,375]`，或 Tab "买入" `[50,130]`。

### 2.2 填代码 / 价格 / 数量

坐标参考：
- 代码框 `[165,165]`、价格框 `[165,235]`（自动填当前价，通常不改）、数量框 `[165,325]`（A 股 ≥ 100 股；或选全仓 / 1/2 / 1/3 / 1/4）
- 买入按钮（红色"买 入(模拟炒股)"）`[190,430]`

一个 type action 完成点击+输入（type 规范见 §6.2，不要先 click 再 type）：

```json
{"name":"type","parameters":{"coordinate":[165,165],"text":"002654"}}
{"name":"type","parameters":{"coordinate":[165,325],"text":"100"}}
{"name":"click","parameters":{"coordinate":[190,430]}}
```

### 2.3 误入搜索子页（极少发生）

带坐标的 type 正常不会跳到搜索子页。若截图确实显示搜索页（顶部 `🔍 股票代码/简拼` + 右侧"取消" + 自制数字键盘），**唯一做法**：click 右上角"取消" `[925,165]` 退回买入页 → 重新 type。**禁**硬输 / 切键盘 / 逐键点自制键盘。

### 2.4 🚨 确认买入三步闭环（事故高发区，严格照做）

| Step | 动作 | 坐标 | 说明 |
|---|---|---|---|
| A | 点"买 入(模拟炒股)" | `[190,430]` | 弹"委托买入确认"对话框 |
| B | 点"确认买入"（红字） | `[685,615]` | **此刻下单成功**，随即弹"委托已提交，合同号xxx" |
| C | 点"我知道了/确定" | `[500,576]` | 关闭后买入页重置（数量空/价格刷新/按钮仍在 全是默认，非未成交） |
| D | 追加 fact 两行 + 立即跳验证 | — | 见下 |

**Step D fact**（两行同时追加；写 text 下轮会丢）：

```
✅DONE: 已下单 <代码> <名称> <数量>股 合同号<xxx>
🔒LOCKED: 本任务禁止再填数量/代码、再点买入/卖出按钮、再点确认买入/确认卖出
```

**下一 action 必须**跳持仓 `[350,130]` / 查询 `[450,130]` / 撤单 `[250,130]`（走 §2.5），**禁留买入页再 click/type**。

**已下单后的误读 → 正确动作**：数量框空 / 买入按钮还在 / 代码还在 — 全是默认重置，**不是"没成功再点一次"的信号** → 跳持仓。

### 2.5 提交后验证（持仓 + 委托双查）

规则：**成交→持仓，未成交→委托，任一命中 = success**。**不以"买入页长什么样"判定**。

```
① 持仓：click [350,130] → 刷新 [950,80] → wait 1s → 截图 → 列表有目标 → terminate success
② 否则查委托：click 查询 [450,130] 或 撤单 [250,130] → 刷新 [950,80] → wait 1s → 列表有目标 → terminate success
③ 两边都无（每页 ≤ 2 次刷新）→ terminate fail，严禁回买入页重提
```

## 3. 卖出

Tab **"卖出"** `[150,130]`。布局与买入相同（代码→价格→数量→卖出按钮），操作与 §2.4 Step A→B→C→D 完全对称（**"确认卖出"单任务只点 1 次**，🔒LOCKED-SELL）：

```json
{"name":"type","parameters":{"coordinate":[165,165],"text":"002654"}}
{"name":"type","parameters":{"coordinate":[165,325],"text":"500"}}
{"name":"click","parameters":{"coordinate":[190,430]}}
```

弹 **"委托卖出确认"** → 点"确认卖出"（红字） → 弹 **"委托已提交"** → 点"我知道了" `[500,576]` → 跳验证（§2.5）。关闭后数量框清空是默认行为。

## 4. 撤单

### 4.1 进入 & 刷新

- 入口：模拟练习区 → **"撤单"** `[250,130]`
- **⚠️ 撤单页不自动更新**，每次进入/每撤一笔必须点右上角"刷新"（C 形箭头）`[885,210]`（**注意 ≠ 买入页的 `[950,80]`**）→ wait 1s → 截图

### 4.2 列表格式

列：委托时间 | 委托/均价 | 委托/成交 | 状态（如 `江波龙 | 买 15:12:43 | 372.06/0.00 | 200/0 | 未成交`）。首行 y≈209，每行高 ≈ 80；按时间倒序；无可撤显示 **"暂无数据"** / **"暂无委托"**。

### 4.3 撤单确认弹窗

点委托行 → 弹 **"委托撤单确认"**：**"撤单"**（红字）`[500,553]` ｜ **"撤单后继续买入"** `[500,613]` ｜ **"取消"** `[500,668]`。

成功后该委托消失或状态变 **"全部撤单"**。点完立即追加 fact：`✅DONE: 已撤单 <股票><代码> <数量>股`。

### 4.4 批量撤单循环

```
loop:
  1. click 刷新 [885,210] → wait 1s → 截图
  2. "暂无数据" / 可撤数=0 → break
  3. click 首行 (y≈209) → 弹确认
  4. click "撤单" [500,553] → wait 1s
  5. fact 追加 "✅DONE: 已撤单 ..."
  6. goto 1
```

上限：单次 ≤ 20 笔；连续 3 轮列表不减少 → `terminate fail`。

### 4.5 汇总

`terminate success`，text 列出：共撤 N 笔 + 每笔股票/代码/方向/数量/时间（来源：fact 的 `✅DONE: 已撤单` 行）。

## 6. 通用规范

1. **📌 fact vs text**（最关键机制）：

   | 字段 | 机制 | 用途 |
   |---|---|---|
   | `fact` | 行级去重追加，**永不删除** | 里程碑 / 锁 / 提交号 / 禁止清单 |
   | `text` | **每轮完全覆盖** | 当前状态 / 下一步临时思路（≤ 200 字） |

   一次性事件（已下单、已撤单、遇弹窗…）**必须写 fact**，前缀：`🔒LOCKED:` / `🚨BLOCKED:` / `✅DONE:` / `📎REF:`。禁把里程碑写 text。

2. **type 永远带 coordinate，没有例外**：写 `{"name":"type","parameters":{"coordinate":[x,y],"text":"..."}}`。系统 parse 阶段直接拒绝裸 type；该 action 内部自动 click + 定向写入，**兼容 EditText / WebView / 自绘控件**（如同花顺代码框）。不要先 click 再 type；内部已 select-all + 整体替换旧内容，无需单独清空（若仍残留则点"清空"按钮）。

3. **交易时间**：A 股 9:30-11:30、13:00-15:00；非交易时段委托排队。

4. **每步后截图确认** click → 预期的弹窗/跳页变化；同一坐标连点 ≥ 2 次无变化 = 必有遮挡（🔒ANTI-STUCK）。
